What we mean by vanilla

The point is to keep Minecraft familiar while giving the community useful tools.

Untouched Mojang jarNo Paper, no plugins. The server file is the one Mojang ships.
Vanilla gameplaySurvival works the way you know it. Nothing swaps out the core game.
QoL on the sideUseful extras like homes, shops and a menu are powered by datapacks and a custom server wrapper.

How to join

It takes about thirty seconds.

  1. Open Minecraft Java Edition.
  2. Choose Multiplayer, then Add Server.
  3. Enter play.van-os.uk and hit Done. See you at spawn.

Server rules

Two simple ones, so everyone can enjoy their time here.

  • No griefing, stealing or raiding.
  • No PvP unless both sides are up for it.

Questions

Is VanOS Java or Bedrock?

VanOS is a Java Edition server.

What does vanilla mean here?

We run an untouched Mojang jar with no Paper and no plugins. Extra features are powered by datapacks and a custom server wrapper, so gameplay stays vanilla with quality-of-life extras on the side.

Can I have my own Skyblock island?

Yes. Every Skyblock player gets a private island, and you can invite friends to co-op.

What are Plots for?

Plots are for planning out your builds before committing, then taking your ideas into Survival.

Who runs VanOS?

VanOS is run by LastOrders and a friendly staff team.
